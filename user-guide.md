# User guide
**Customer:** register -> Businesses -> View services -> choose service and mode -> Confirm. Your token appears under Live queue (estimate only). Cancel only while *waiting*.
**Business:** Dashboard -> register business (wait for approval) -> add services/counters -> Queue: Call next, Start, Complete, Skip, Recall, Pause. Show customers `queue-display.html?b=<business id>` on a TV.
**Admin:** approve/reject/suspend businesses, manage customers and categories, watch Monitoring.
